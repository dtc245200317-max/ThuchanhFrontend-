BÀI TẬP: NHÚNG CSS VÀO TRANG HTML

Phần 1: Nhúng CSS theo dạng Inline Style

Tiêu đề sử dụng Inline Style

Đoạn văn này được đổi màu bằng cách sử dụng thuộc tính style viết trực tiếp trong thẻ HTML.

Phần 2: Nhúng CSS theo dạng Internal Style

Tiêu đề sử dụng Internal Style

Đoạn văn này được đổi màu bằng thẻ <style> định nghĩa trong phần <head> của trang.

Phần 3: Nhúng CSS theo dạng External Style

Tiêu đề sử dụng External Style

Đoạn văn này được đổi màu bằng tệp CSS bên ngoài (style.css) được liên kết qua thẻ <link>.
